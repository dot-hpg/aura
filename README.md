# AURA Automation website

Website for AURA Automation (Smart Homes Telangana), a smart home automation company in Hyderabad.

- `index.html` is the whole site: a single static page with no build step.
- The consultation form posts to Netlify Forms when hosted on Netlify. On other hosts it falls back to WhatsApp.

## Deploy

**Vercel:** import this repo at vercel.com/new. Framework preset: Other. No build command needed.

**Netlify:** Add new project → Import from Git → pick this repo.
